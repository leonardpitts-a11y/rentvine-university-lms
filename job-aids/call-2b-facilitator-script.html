Maintenance & Work Order Lifecycle

Purpose: This is a full trainer/facilitator script covering the Maintenance tab end to end: the work order list, recurring work orders, work order templates, creating a work order (property, description, photos, vendor/technician assignment, dates, priority, assignee, estimated cost), the work order details page (estimates, bills, invoices, chat, emails, files, activity log), the vendor portal experience, closing out a work order, work order settings (general, visibility/sharing, statuses, appointment settings), and Fixie, the AI-powered maintenance assistant. Use it to prepare for explaining these processes to a new team member, an owner, or yourself while practicing. Lines marked "Suggested trainer language" are ready-to-use scripting you can say almost word for word.

Introduction

Good morning. Today's session is going to be based on maintenance — the work order life cycle, and how work orders function in the system.

Anything that has to do with maintenance is going to be in the Maintenance tab on the left-hand side. Once you click that drop-down, you'll see several items, and where we're going to spend most of the day today is the Work Order section.

Work Order List and Recurring Work Orders

Once you click on Work Orders, you'll see a work order list — a complete list of every single work order you have in the system. The default statuses shown are anything that's Pending or Open. If you need to remove that filter, you can, or you can click the little funnel icon on the right side and find work orders with a specific status, such as ones that have already been closed out.

Outside of the work order list, you also have the ability to set up Recurring Work Orders. If you have something fairly frequent (every month, every two weeks, every week, whatever the case may be), you can create a recurring work order by clicking the green Actions button in the top right.

Work Order Templates

The next section is Work Order Templates. With work order templates, you have the ability to set up templates so you can use them whenever your property management company is creating work orders. The reason behind it is you don't have to fill out any of the descriptions or generic information every time — you can create the template and already have it pre-populated.

You'll even have the ability to auto-select the vendor. So if you work with the same pool cleaning company every time you have a pool cleaning work order, you can create that as an actual template.

Creating a Work Order: Property, Location, and Lease

If you click Add Work Order in the top-right section, you'll see the work order template drop-down — select one if applicable, or just continue with the actual creation.

First, enter the property. Once the property shows up, you'll see the property details come up: the property, the portfolio it belongs to, the operating balance, the maintenance limit amount, and any other notes entered on the property.

You can also enter the incident location, so the vendor knows exactly where the problem is at the property, and you can select a lease for this property. In this example, the lease did not populate automatically because all the leases at that property are currently closed — if there was someone currently living at the property, it would automatically populate as soon as you click the property.

If you attach the work order to a closed lease, you have the ability to either mark that the tenant is financially responsible, or that the unit is vacant. If the unit is vacant, you're just attaching it to that old lease and the tenant is no longer financially responsible.

Creating a Work Order: Description, Photos, and Files

Outside of the lease section, you also have the ability to enter your description — exactly what the work order is for (for example, "broken door").

You'll have the ability to upload documents: either an issue photo or a file upload, depending on what you prefer. The issue photo is just an actual image of the initial problem, and the file upload is for anything outside of that — a receipt, an extended file for a material list, or the actual invoice/estimated cost that a vendor provided to you.

Creating a Work Order: Assigning to a Vendor or Technician

Besides that, you have the ability to assign the work order to either a vendor or an internal technician. An internal technician is somebody who works within your company — a handyman or internal maintenance staff. That's what the other sections of the Maintenance tab are about: price book, technicians, and calendar, which are all part of internal maintenance.

If you stick to a regular vendor, you have the ability to auto-select which vendor you want to work with — search for the vendor and attach it to the work order. Or, if you don't want to attach a vendor yet, you have the ability to request estimates afterward instead.

Creating a Work Order: Dates, Status, Priority, and Assignee

Next, you have the ability to enter the date due for the work order — when you want it to be completed by. You also have the ability to enter a scheduled start date; this does not mean it's the actual date the work order will be done, it's just what you're expecting.

You also have the ability to set a status. The system defaults to Open. And you have the ability to select a priority: Low, Medium, or High — depending on what the work order is required for.

Next, you have the ability to add an assignee — anyone in your actual system, whether that's your maintenance coordinator or even yourself if you want to make sure you're assigned to the work order. All the assignee field does is let you figure out who's supposed to receive notifications for specific items happening on the work order.

Creating a Work Order: Estimated Cost and Approval Toggles

The next part is your estimated cost. What the estimated cost does is hold back funds from being paid out to the owner — think of it like a reserve. Whenever you're processing and paying out bills directly, it holds it back from the owner's portfolio, so when you go to the owner distribution, it knows to hold back for that work order. Until the work order has a bill created, entering the estimated cost does the same thing, so you're able to hold back funds for those big jobs without worrying about having enough funds available.

The next toggles are: Owner Approved, which just lets you know internally whether the work order has been approved, yes or no; and whether the work order has been published to your tenant or your owner contact — that lets them see it directly on their portfolio or portal.

Other than that, if you click Save, you're creating the work order.

Work Order Details Page Overview

Once you create your work order, you're sent back to the details page. This is basically the same information you just entered: your details, residents, owners, issue photos, custom fields, or reminders if applicable. But the next section to talk about is Estimates.

Estimates: Requesting and Entering Vendor Estimates

You have the ability to submit an estimate from the vendor side — you can either enter a new estimate or request one, completely up to you.

If you request one, you select who the vendor is, set a deadline, and it sends a vendor notification requesting an estimate from them.

If you enter a new estimate directly (for example, if a vendor gives you the estimate over the phone), you enter the vendor, the amount they quoted, and the completion date, and hit Create. Now you'll see the two estimates: one labeled as requested (the vendor will provide the actual estimate through their portal), and one already entered with comments recorded.

Estimates: Approving and Sending for Owner Approval

Once both estimates are in, you can either approve it, send it for owner approval, or delete the estimate. If you send both for owner approval, it may ask you to enter any markups or comments before sending.

You have the ability to decline an estimate on behalf of the owner, or approve it. If you approve one because it's a better amount, you can also notify the vendor that their estimate has been approved. The status changes to Approved, and the other estimate shows as not winning the bid.

If you go back to the details page and refresh, you'll see that the vendor has been auto-selected on the work order, and the estimated cost automatically updates to match the approved amount — you don't have to manually enter it yourself.

Bills and Invoices from the Work Order

Outside of the estimate sections, you have the ability to add bills. If you want to create bills directly from the work order, click the green Actions button, Create the Bill, or Add an Existing Bill.

You also have the ability to process invoices. If the vendor sends you an invoice, you can process it from the work order — this is only achievable if the vendor closes out the work order on their end and uploads the invoice. If they don't upload the invoice, you'll have to do it manually by clicking Actions and creating a bill through that invoice directly.

Chat, Emails, Files, and Activity Log

Outside of the bill section, you have the ability to chat. You can communicate with the resident, the cosigner, or the vendor at the same time — you choose exactly who you're contacting, and you have the ability to remove specific participants. The same functions work on their side of the chat, except they cannot remove you from the actual chat, so you're always aware of what's coming in from that work order.

Outside of chat, you also have the ability to send emails. When composing an email, you can see exactly who you're emailing — the tenant and the owner (as long as it's published and attached to their lease/portfolio) can be toggled, and you can add your actual vendor. You can also add additional recipients, or use an email template if you just want to let them know the old-fashioned way (for example, that a work order has been assigned to them).

Next is the Files section — anything added outside of the actual issue image gets entered into Files, and you'll be able to see the files you've added. Lastly, you have the Activity tab, which gives you a direct activity/time log so you can see exactly what's been happening within the work order overall.

Vendor Portal: Accepting and Scheduling a Work Order

You can track exactly what's happening in the work order — for example, once a vendor accepts a work order, you can switch into the vendor portal view to see what the vendor sees.

In the vendor portal, the vendor has the ability to look into what's overdue, pending, open, closed, and their vendor ratings. Once they click on the work order, they have the ability to either accept or reject it. If they accept, it populates a time/schedule log, and they can select a different time, or accept without scheduling. If a time works, they set the work order for that time.

Vendor Portal: Completing the Work Order and Submitting an Invoice

From there, the vendor has the ability to communicate with the tenant to confirm scheduling. Once they've done the work, they click Complete, which takes them to a two-step process: enter complete comments, resolution photos, or any additional files, then proceed to the next section.

They can submit the invoice now (yes or no). If they select no, they can still save it. If they select yes, it asks whether they'd like to upload or create it — if they create it, they enter the invoice number, the due date, the line item description, and the amount, then submit it. Once submitted, the status changes to Closed, which closes out the work order from the vendor side.

If the vendor was not able to get the invoice processed at the same time, that's okay — if they go into the invoice section, they have the ability to submit an invoice, but it will not be attached to that work order once the work order has already been closed. There's nothing they can do to reattach it at that point, so they just have to submit the invoice on their side directly.

Closing Out the Work Order and Converting the Invoice to a Bill

Once the work order has been closed and everything's done, switch portals back to the admin/manager side and go into the work order. You'll see the vendor, the closed dates, the scheduled maintenance window, and the completed comments. The system will tell you there's a pending processing invoice.

You'll also see the estimated cost is still there and the work order still shows open. Clicking through takes you to the invoice that was just created — enter the actual account (for example, Repairs), and everything else looks good, then convert this into a bill.

Now the work order is done — it goes back into a closed status, and you can send a review request on the vendor's behalf.

Work Order Settings: General Settings

Outside of the work order life cycle, let's talk about the settings for work orders. Click your initials in the bottom-left corner and go to Settings, then the Maintenance section, where you'll find your work order settings.

The first section covers your generic settings: what statuses are default when work orders are created (Open; recurring work orders are also created as Open). When a tenant submits a request, it defaults to Requested. When a tenant resolves their own maintenance issue, the status goes to Resolved and Closed.

You can also change the work order status when creating a bill if that's enabled (typically Closed/Completed). You can also auto-assign work orders submitted by tenants based on who's assigned to the lease — this only works if the lease has an assignee; if it doesn't, nothing will populate. This is for internal maintenance, which can be covered separately if needed.

Work Order Settings: Visibility, Sharing, and Vendor Management

The next portion is Visibility and Sharing. You can configure the maintenance limit, whether to default-publish the work order with the owner when created by the manager, with the tenant when created by the manager, and whether to automatically share the work order with an owner when submitted by a tenant. You can also show the tenant's name on the work order PDF, as well as the owner's name on the work order PDF, so your vendor is aware of who's who.

Lastly, you have Vendor Management settings: default vendor reviews enabled (you can toggle this off if you don't want to send vendor reviews), and whether vendors are allowed to upload invoices (you generally want this toggled on, since you'll want your vendors to be able to submit invoices).

There's also a work order automation setting for what status gets set whenever the vendor closes it — typically set to open, job completed, with an invoice.

Work Order Statuses

Outside of your normal settings, you also have the ability to look at your specific work order statuses. Anything without an ellipsis on the right side is a default status — you can change or update it, but not delete it. You have the ability to create your own custom statuses (for example: Assigned to Vendor, Job Completed - Need to Create a Bill, Resident & Close, Job Completed with or without Invoice). If you click Add Status, you have the ability to select exactly what the status is for.

Appointment Settings

You also have the ability to select your appointment settings — the scheduling time-window framework. You can see which days of the week vendors are available to work, and the time zone (based either on the manager's location or the location of the property requesting maintenance — you can select which).

You have the ability to select the start and end time of your actual work window (for example, 9 a.m. to 6 p.m.), and how long each appointment window is: an hour and a half, an hour and 45 minutes, an hour and 15 minutes, one hour flat, or two hours. With a 2-hour window, the schedule would run 9 to 11, 11 to 1, and so on until 6 p.m.

You also have the ability to select the number of time windows shown, and the number of days available for scheduling — how far out into the year vendors can schedule (you can set this all the way up to 255 days).

Lastly, you have the ability to set a buffer. This means you won't be able to schedule anything within that buffer window — for example, a buffer of one day means the earliest available scheduling is tomorrow, not today. And you have the ability to set up reminders — SMS text messages sent to tenants to confirm the actual maintenance appointment.

Fixie: AI-Powered Maintenance Assistant

The last setting to talk about is AI agents. We have an AI agent called Fixie. Fixie comes in whenever a tenant is submitting a work order — the AI tries to help the tenant fix and resolve the issue on their own instead of just sending it straight to you.

From the resident portal, a tenant can create a maintenance request. With Fixie, they can take a photo, record a video, or just talk through the issue — recording a video is recommended, since it helps the AI figure things out faster.

Fixie starts a diagnosis based on the request, asking follow-up questions (for example, what kind of issue it is, whether it's physical damage). It thinks through the issue and tries to solve it — for example, asking if a quick video can be taken to figure out what's going on, or asking the tenant to describe further so it can offer next steps.

If the AI can't resolve it, the tenant can proceed with creating the actual work order. Once that work order is created, it appears in your maintenance section as pending/requested, and you'll be able to see Fixie's comments under the details of the work order so you can see exactly what the AI already tried.

Closing

That's pretty much what we covered today: the full work order life cycle, work order templates and settings, the vendor portal experience, and Fixie, the AI-powered maintenance assistant.
